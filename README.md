# FITLOG

FITLOG is a modern workout library and workout planning application built with Next.js.

## Features

- Workout Library
- Workout Details
- Add workouts to Today's Plan
- My Plan
- Save workouts for later
- Mark workouts as completed
- Responsive design
- Local storage support

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
